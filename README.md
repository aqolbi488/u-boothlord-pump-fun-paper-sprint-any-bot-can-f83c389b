A small deterministic paper-trading bot for pump.fun replay data: it watches each newly created mint, buys a fixed 0.1 SOL stake only when early trading confirms momentum (at least 3 trades and price up 8% from creation), holds at most 5 positions, and exits every position on a +35% take-profit, a −28% stop-loss, or after 1200 slots. All decisions come from slot numbers and curve reserves only — no clock, no randomness — so the run is fully reproducible.

## Run it

```sh
node main.ts
```
