A small deterministic paper-trading bot for pump.fun replay data: it watches each newly created mint, buys a fixed 0.1 SOL stake only when the price pulls back 15–30% from its creation price (a dip, not a collapse, with at least 5 trades behind it), holds at most 5 positions, and exits every position on a +20% take-profit, a −12% stop-loss, or after 1200 slots. All decisions come from slot numbers and curve reserves only — no clock, no randomness — so the run is fully reproducible.

## Run it

```sh
node main.ts
```
